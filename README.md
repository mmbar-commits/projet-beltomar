# Projet Beltomar — Simulation 3D Interactive

Visite 3D interactive du projet **Beltomar × Afriquia · Mini Brahim** (Ouled Azzouz, Casablanca — `TF 179259/63`).

## Contrôles
- **Déplacement** : `ZQSD` / `WASD` (marche adulte 1m80 ou conduite SUV)
- **Regard** : flèches du clavier ou clic-glisser souris (style Street View)
- **Vue 1ère / 3ème personne** : bouton `1ère pers.` / `3ème pers.` ou touche `V`
- **Plan 2D / Plan Architecte** : cliquez directement sur n'importe quel point (`SS`, `RDC`, `R+1`) pour vous y téléporter
- **Voirie** : basculez entre les modes `Actuel` (P3014 30 m) et `Futur` (P3014 60 m + OA65)
