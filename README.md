# Projet Beltomar — Version Heavy Ultra PBR 3D

Édition photoréaliste **Heavy PBR** de la simulation 3D **Beltomar × Afriquia · Mini Brahim** (Ouled Azzouz, Casablanca — `TF 179259/63`).

## Améliorations visuelles (Option 2)
- **Moteur Three.js r169** avec étalonnage **ACES Filmic** et ombres **4096×4096 PCFSoft**
- **3 Ciels HDRI 360° photographiés** (Poly Haven CC0) : *Soleil*, *Heure Dorée* et *Soir* — reflets physiques réels sur les vitrines, carrosseries et inox
- **Textures PBR scannées 1K** (Diffuse + Normal + Roughness) sur enrobé, béton parvis, pavés, enduit façades, lames bois, terrazzo et pelouse
- **Post-processing temps réel** : Occlusion Ambiante **GTAO** + **Bloom** cinéma (désactivable via le bouton `✨ Ultra FX`)
- **Modèles 3D `.glb` / `.gltf` réels** : voitures détaillées (peinture clearcoat), personnages 3D animés & réalistes, mobilier de café Oasis Café, luminaires suspendus, plantes tropicales, frigos vitrés Mini Brahim et bureaux 1er étage
